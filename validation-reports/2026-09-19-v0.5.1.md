# Validation report — angou v0.5.1

**Date**: 2026-09-19
**Spec**: none. A dependency bump, plus one feature adopted from what the bump
made available.
**Scope**: `fynedesygn` v0.1.5 → v0.1.28, twenty-three releases. The bump itself
needed no source change. One was then made deliberately: `internal/gui/app.go`
declares the navigation shapes this window allows.

---

## Summary

angou was the last of the three programs still on an early fynedesygn. The bump
is clean: the window builds, every test passes and no section, dialog or
operation needed touching. That is the result the library's additive discipline
is supposed to produce across twenty-three releases, and it is worth recording
that it did.

What angou gains is entirely in the library, and three of the items are fixes to
bugs this window had:

- **A result banner no longer takes every click in the window** (library
  0.1.13). A banner was a popup, a popup is an overlay, and Fyne routes pointer
  events to the top overlay instead of to the content — so for the six to twelve
  seconds a banner was up, the first click anywhere went to dismissing it rather
  than to the control it was aimed at. Hover tips had the same defect (0.1.12).
- **A banner is legible over a busy section** (0.1.15). The status tint is
  translucent so text stays readable over it; moved into a content layer it had
  nothing underneath but the section, and a busy section read straight through
  the message.
- **A refused operation names what is holding the window** (0.1.20, 0.1.21)
  rather than saying "something is already running", and offers Cancel when that
  operation has one.

Appearance settings move from Fyne's preference store into a file the user can
read (0.1.10), with the old values read once, so a configured window opens the
way it was left.

**The navigation's shape is adopted** (library 0.1.10, spec 013): titles with
icons, icons alone, or hidden with the content taking the window, down the left
or along the top, with one control in the header and `Ctrl+B` to hide. Six lines
in `shellOptions`, because the library holds the control, the shortcut and the
storage; a program only declares what it allows, and one that declares nothing
keeps the window it has.

The icons-only shapes are what the declaration is worth, and they are only
usable because every section already had an icon of its own —
`TestEverySectionHasAnIconForTheIconsOnlyShapes` pins that, since a section
added later without one would draw a generic picture to guess at.

## Tests

`go test ./...` — 9 packages, all pass. No existing test needed changing,
including `internal/gui`, which exercises every section headlessly in every
colour scheme. Two were added for the navigation shapes: one that the window
offers all three modes and both placements, one that every section has an icon.

The library's `fynetest.Walk` began descending `container.Split` in 0.1.26,
which can change the object count a structural walk sees. No test here asserted
such a count, so nothing broke.

## Code quality

`make lint` — 0 issues, pinned golangci-lint v2.12.2.
`go vet ./...` — clean.

## Security

`govulncheck ./...` — no vulnerabilities found.

The bump adds no new module to the graph and no new runtime dependency: Fyne
stays pinned at v2.8.1 and fynedesygn's only required dependency is Fyne. No
code in this repository that touches key material was changed — the bump is
confined to `internal/gui`, which has never handled key material.

## Release safety

Rollback is one line in `go.mod`, a `go mod tidy` and the removal of two fields
from `shellOptions`; no data, no file format
and no on-disk layout changes with this release, with one exception worth
stating: appearance preferences move to a settings file. The old preference
keys are read once when the file is absent, so a downgrade would read the
preference store again and find the values still there — the migration copies
rather than moves.

## Checks against the release procedure

- `VERSION`, the `**Version**` line in `README.md` and the newest changelog
  heading all read `0.5.1`. They did not agree before this release: `VERSION`
  said 0.5.0 and the README said 0.4.0, which is why a check for it has been
  added to `.claude/CLAUDE.md`.
- The GUI builds with CGO and `-tags migrated_fynedo`, which the Makefile
  already carried.
